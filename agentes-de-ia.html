Chat × agente

O mesmo pedido, duas respostas.

Escolha um pedido. O chatbot explica como fazer. O agente faz, porque tem acesso às ferramentas certas e um jeito de conferir o que fez.

Chatbotresponde

Agenteresolve

    A diferença não está na inteligência do modelo. Está em três coisas: ferramentas para agir, permissão para usá-las e um ciclo para conferir o resultado.

    02
    O ciclo

    Pensa, age, observa. E repete até terminar.

    Todo agente roda o mesmo ciclo. Avance passo a passo e veja o agente errar o preço, mudar de plano e parar para pedir a sua confirmação antes de gastar dinheiro.

    Tarefa: ache um voo para Recife na sexta, até R$ 900, e reserve.Passo 0 de 11
    1. Pensadecide o próximo passo
    2. Ageusa uma ferramenta
    3. Observalê o resultado
    4. Vocêaprova o que importa
    5. Entregatermina a tarefa
      0 voltas no ciclo

      Cada volta no ciclo custa tempo e dinheiro. Por isso um bom agente tem limite de passos e pede confirmação antes de qualquer ação que não dá para desfazer, como pagar, enviar ou apagar.

      03
      Ferramentas

      Um agente só faz o que as ferramentas deixam.

      Ligue e desligue as ferramentas e veja quais tarefas o agente consegue cumprir. É assim que se dá poder a um agente, e também como se limita.

      Ferramentas do agente1 ligada

        Hoje existe um padrão aberto para ligar ferramentas a agentes, o MCP (Model Context Protocol): cada sistema vira uma tomada que qualquer agente compatível sabe usar. A regra de ouro continua a mesma: dê ao agente só as ferramentas que a tarefa precisa.

        04
        Vale a pena?

        Cinco perguntas antes de colocar um agente para trabalhar.

        Pense numa tarefa do seu trabalho e responda. O resultado diz se ela é boa para um agente, para um assistente que sugere e você aprova, ou se ainda não é hora.

        1. A tarefa se repete toda semana?

        2. Os passos são parecidos toda vez?

        3. Dá para conferir se o resultado está certo?

        4. Um erro é fácil de desfazer?

        5. Os dados ficam num sistema, planilha ou e-mail que dá para acessar?

        Responda as cinco

        –

        Cada resposta muda o resultado.

        Cuidado 01

        Permissão mínima

        Se a tarefa só precisa ler e-mails, o agente não precisa enviar. Cada ferramenta a mais é um risco a mais.

        Cuidado 02

        Você aprova o que não volta

        Pagar, enviar para cliente e apagar dados pedem confirmação de uma pessoa. Sempre.

        Cuidado 03

        Tudo fica registrado

        Cada passo, ferramenta e resultado vai para um registro. É assim que se descobre por que algo deu errado.

        Cuidado 04

        Limite de passos e de gasto

        Um agente preso num erro pode repetir o ciclo sem parar. Um teto de passos e de custo evita a surpresa na fatura.
